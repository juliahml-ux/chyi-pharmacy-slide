# 三師爸簡報製作 ── 衛生福利部嘉義醫院 藥劑科

本專案為衛生福利部嘉義醫院藥劑科專屬之高品質簡報製作庫，整合了李俊儀教授 **SOIL 教學心法**（六顆引擎）、林長揚 **30 原則**，以及現代化 **Reveal.js 網頁簡報技術**，專為臨床案例教學、院內科會報告、新藥進藥審查與藥事行政管理量身打造。

## 🛠 簡報產出成果與特色

### 115年09月份 藥庫工作報告 (`科會簡報/index.html`)
* **形式**：免安裝、跨平台、高解析度的 Reveal.js 單檔網頁簡報（直接雙擊即可放映）。
* **特色亮點**：
  * **智慧藥櫃管理守則（三大卡片）**：完整保留 1~3 級管藥雙人盤點、4 級及公藥單人盤點；新增智慧藥櫃與冰箱藥品（Anxicam inj、Mounjaro inj 10mg、Xolair inj）Barcode 條碼讀取覆核；備用鑰匙封存交班本，**僅限系統異常或緊急災變時拆封啟用**。
  * **調配與窗口優化**：Tosho 包藥機入盒規範提報主管會議；窗口叫號燈新增「住／出院領藥」分流。
  * **行政與疫苗施打季**：完整收錄年休假 9月75%/11月90% 規範；門診假日發放與社區外展接種冷鏈溫控重點。
  * **原生同仁休假統計長條圖**：以 Chart.js 將 18 位同仁達成率以綠/黃/紅三色基準線視覺化，完全免去模糊照片貼圖。
  * **四大品質指標趨勢曲線圖**：動態繪製 1~9 月庫存週轉率、月庫存消耗比、住院退藥率（3.43% 年度新低）與退藥品質不良率（0.84% 合格）。
  * **人性化操作**：每頁頁碼置中顯示於螢幕下方（格式 `x / 8`），徹底避開右下角方向箭頭控制鍵。

## 🎮 簡報操作快捷鍵

| 按鍵 | 功能說明 |
| :--- | :--- |
| **`Space`（空白鍵） / `→`** | 前進至下一頁 |
| **`←`** | 返回上一頁 |
| **`F`** | 切換全螢幕放映模式 |
| **`ESC`** | 開啟 8 頁鳥瞰總覽九宮格，方便快速跳頁 |
| **右下角箭頭** | 滑鼠直接點擊上下左右方向控制鈕 |
