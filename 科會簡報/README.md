## 📋 常見科會簡報結構範本

### 範本 A：臨床案例討論（Case Report / CBL）
1. **封面**：題目、報告人（衛生福利部嘉義醫院 藥劑科 葉藥師）、指導醫師/主管、日期
2. **引起動機**：核心臨床問題或震撼數據（例如：嚴重藥物交互作用、特殊 ADR）
3. **病人基本資料**：Age/Sex, CC（主訴）, PMH（過去病史）
4. **檢驗與檢查數據**：Vital signs, Renal/Liver Labs, Culture report
5. **目前用藥明細**：現有處方清單與潛在交互作用分析
6. **藥師臨床介入 (Intervention)**：藥物建議、劑量調整依據（引用 2026 最新指引）
7. **治療成效追蹤**：Outcome & Follow-up
8. **喚起行動與討論 (Discussion)**：Key takeaways 與科會討論題

### 範本 B：新藥進藥審查（Formulary Review）
1. **藥品基本資料**：商品名/學名、適應症、健保代碼與價格
2. **臨床效益與試驗數據**：樞紐試驗（Pivotal Trials）、NNT/NNH
3. **現有同類藥品比較**：療效、副作用、給藥頻率、腎功能調整對照表
4. **用藥安全與高警訊考量**：禁忌症、Black Box Warning、特殊監測指標
5. **健保給付規定與綜合評估**：給付條文重點與藥劑科審查建議

## 🚀 如何在 Antigravity 中開始

葉藥師只要在對話中貼上案例資料或提供報告主題，並說：
> *「請用 `soil-teaching-deck` 幫我把這個臨床案例做成科會簡報 PPT」*
> 或
> *「這份新藥資料要報科會，幫我轉成 10 頁簡報」*

系統將全自動遵循李俊儀教授 SOIL 六引擎心法與林長揚簡報規範為您排版產出！
